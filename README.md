POS is a powerful and modern web-based Shop and Inventory Management Template built for businesses looking to streamline their store operations. It's packed with essential features for managing products, sales, purchases, users, and more — all through an intuitive dashboard UI.

## 🚀 Features

- ✅ **Product Management**
- ✅ **Barcode Management**
- ✅ **Sales Management**
- ✅ **Purchase Management**
- ✅ **Expense Management**
- ✅ **Supplier & Customer Management**
- ✅ **Tax Rate Management**
- ✅ **User & Role Management**

## 📊 Dashboard

The elegant and responsive dashboard provides an at-a-glance view of:
- Purchase & sales analytics
- Top-selling products
- Expired items
- User stats and more
